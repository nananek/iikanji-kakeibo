# いいかんじ家計簿

個人向けの家計簿 Web アプリケーション。簿記の知識がなくても使える**出納帳モード**と、複式簿記の**仕訳伝票モード**を備え、医療費控除や社会保険料など**確定申告・年末調整**に必要な集計を自動で行います。

## 主な機能

### 出納帳モード

日付・収支の種類・口座・費目・金額・摘要を入力するだけで、裏側で自動的に複式簿記の仕訳伝票を生成します。簿記を知らなくても家計管理ができます。

### 仕訳伝票モード

借方・貸方を自由に入力できる本格的な仕訳入力画面。行の動的追加と貸借バランスのリアルタイムチェック付き。

### CSV 明細取込

銀行口座やクレジットカードの CSV 明細をアップロードし、**列マッピング UI** で日付・摘要・入金・出金の列を指定して一括取込。Shift-JIS / UTF-8 を自動判定。

### 医療費管理

受診者・病院名・治療内容・支払額・保険補填額を記録。年間の自己負担額と控除対象額（10 万円超過分）を自動計算し、確定申告の医療費控除に対応します。

### レポート

| レポート | 内容 |
|---|---|
| ダッシュボード | 月次 / 年次の収支サマリーと Chart.js による月別推移グラフ |
| 残高試算表 | 全勘定科目の借方・貸方・残高一覧 |
| 収支計算書 | 月次 / 年次の収入・支出を科目別に内訳表示 |
| 確定申告用集計 | 社会保険料・生命保険料・地震保険料・医療費・寄附金・iDeCo・源泉所得税・住民税を税区分ごとに集計 |

### 勘定科目管理

ユーザー登録時に約 40 科目の標準勘定科目を自動投入。確定申告用の税区分（`tax_category`）付き。独自科目の追加・編集も可能。

## 技術スタック

- Python 3.12 / Flask 3.x
- PostgreSQL 16
- SQLAlchemy 2.x / Alembic (Flask-Migrate)
- Flask-Login / Flask-WTF
- Bootstrap 5.3 (CDN)
- Docker Compose

## セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/nananek/iikanji-account-personal.git
cd iikanji-account-personal

# 環境変数ファイルを作成
cp .env.example .env
# 必要に応じて .env の SECRET_KEY を変更

# 起動（初回はマイグレーションと勘定科目区分の投入を自動実行）
docker compose up -d
```

ブラウザで http://localhost:5001 を開き、ユーザー登録してください。登録時に標準勘定科目が自動で投入されます。

```
│   ├── auth.py          #   認証
│   ├── dashboard.py     #   ダッシュボード
│   ├── cashbook.py      #   出納帳モード
│   ├── journal.py       #   仕訳伝票モード
│   ├── csv_import.py    #   CSV明細取込
│   ├── medical.py       #   医療費管理
│   ├── reports.py       #   レポート
│   └── accounts.py      #   勘定科目管理

│   ├── seed.py          #   標準科目の初期データ

├── forms/               # Flask-WTF フォーム
├── templates/           # Jinja2 テンプレート
└── static/              # CSS / JS
```
