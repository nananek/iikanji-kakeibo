**出納帳に入力するだけで、裏で仕訳が自動生成。**

## 主な機能

### 出納帳モード

日付・収支の種類・口座・費目・金額・摘要を入力するだけで、裏側で自動的に複式簿記の仕訳伝票を生成します。簿記を知らなくても家計管理ができます。

### 仕訳伝票モード

借方・貸方を自由に入力できる本格的な仕訳入力画面。行の動的追加と貸借バランスのリアルタイムチェック付き。

### 明細取込 (CSV / OFX / Web)

銀行口座やクレジットカードの明細を3つの方法で一括取込:
- **CSV取込** — 列マッピング UI で日付・摘要・入金・出金を指定。Shift-JIS / UTF-8 自動判定
- **OFX取込** — 銀行ダウンロードの OFX/QFX ファイルをそのまま読込
- **Web取込** — Webページのテキストを貼り付けるだけ。AI が明細を自動抽出

確認画面の共通機能:
- **科目自動推定** — 過去の仕訳履歴から摘要に応じた費目を自動提案
- **一括科目設定** — ドラッグ選択した行にまとめて費目を設定
- **日付編集** — クリックで日付を個別変更、一括日付設定（全行/選択行）
- **全カラムソート** — 行番号・日付・摘要・入金・出金で昇順/降順ソート
- **年度制限チェック** — 未開設年度・確定済み期間の行をバッジ表示し、日付補正または元入金変換を選択可能
- **stickyツールバー** — 操作ボタンがスクロールに追従

### AI 証憑仕訳

領収書・給与明細・請求書の画像をアップロードすると、AI が内容を解析して複数の仕訳案を提案。OpenAI / Google Gemini / Anthropic Claude に対応。

### 月次比較・着地予測

科目別の12ヶ月推移を一覧表示。費用・収入を**固定／変動／随時**に分類し、経過日数から月末の着地予想を自動算出。ドーナツグラフと積み上げ棒グラフで構成比を可視化。

### 医療費管理

受診者・病院名・治療内容・支払額・保険補填額を記録。年間の自己負担額と控除対象額（10 万円超過分）を自動計算し、確定申告の医療費控除に対応します。

### 月次確定・年度管理

月ごとに帳簿を「確定」して編集をロック。確定済み期間の仕訳は追加・変更・削除が不可になり、帳簿の整合性を保護します。年末には損益振替仕訳を自動生成。

前々年以前の年度は明示的に「開設」しない限り仕訳を打てない安全設計。インポート時に古い年度の取引が含まれる場合は、無視するか当年1/1付の元入金仕訳に変換するかを選択できます。

### 監査用アカウント

税理士・公認会計士向けの監査用アカウントで、個人ユーザーのデータに安全にアクセス:

| レベル | 名称 | できること |
|--------|------|-----------|
| Lv1 | 集計結果のみ | 確定申告用集計の閲覧のみ |
| Lv2 | 税務科目のみ | 指定された税務科目の閲覧・編集。非公開科目は「事業主」勘定で隠蔽 |
| Lv3 | 本人同等 | 個人ユーザーと同じ全操作 |

- **提出ロック** — Lv2では「提出」操作により、税務科目を含む伝票が本人側でimmutableに
- **部分編集** — Lv2監査者は税務科目の行のみ編集可能。非公開科目行は自動バランスされ編集不可
- **科目隠蔽** — 非公開科目は一覧・元帳・試算表すべてで「事業主」に差し替え表示
- **ログイン分離** — 個人用と監査用で別々のログイン・登録ページ

### レポート

| レポート | 内容 |
|---|---|
| ダッシュボード | 月次 / 年次の収支サマリーと Chart.js による月別推移グラフ |
| 残高試算表 | 全勘定科目の借方・貸方・残高一覧（月次表示対応） |
| 総勘定元帳 | 科目別の取引履歴と残高推移。月区切り・期間絞込・モーダル編集対応 |
| 収支計算書 | 月次 / 年次の収入・支出を科目別に内訳表示 |
| 月次比較 | 12ヶ月の科目別推移・着地予測・区分分析グラフ |
| 確定申告用集計 | 社会保険料・生命保険料・地震保険料・医療費・寄附金・iDeCo・源泉所得税・住民税を税区分ごとに集計 |

### PWA 対応

ホーム画面に追加してネイティブアプリのように利用可能。Service Worker によるキャッシュでオフライン表示にも対応。

### Passkey (WebAuthn) 認証

パスワードに加え、指紋認証や Face ID などの **Passkey** でログイン可能。設定画面から Passkey の追加・管理・削除ができます。WebAuthn 対応ブラウザで自動的にボタンが表示されます。

### 勘定科目管理

ユーザー登録時に約 40 科目の標準勘定科目を自動投入。確定申告用の税区分（`tax_category`）付き。独自科目の追加・編集・無効化が可能。無効化時は残高を指定科目に振替えます。

## 技術スタック

- Python 3.12 / Flask 3.x
- PostgreSQL 16
- SQLAlchemy 2.x / Alembic (Flask-Migrate)
- Flask-Login / Flask-WTF
- py_webauthn (Passkey / WebAuthn)
- Bootstrap 5.3 (CDN)
- Docker Compose

## セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/nananek/iikanji-kakeibo.git
cd iikanji-kakeibo

# 設定ファイルを作成
cp docker-compose.yml.example docker-compose.yml
cp .env.example .env
# 必要に応じて .env の SECRET_KEY やポート番号を変更

# 起動（初回はマイグレーションと勘定科目区分の投入を自動実行）
docker compose up -d
```

ブラウザで http://localhost:5001 を開き、ユーザー登録してください。登録時に標準勘定科目が自動で投入されます。
