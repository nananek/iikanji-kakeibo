{{ operator.name }} (以下「当方」といいます) は、家計簿アプリケーション 「{{ operator.service_name }}」 (以下「本サービス」といいます) における 利用者の個人情報および本サービス内のデータの取扱いについて、本 プライバシーポリシー (以下「本ポリシー」といいます) を定めます。

1. 取得する情報

本サービスでは以下の情報を取得します:

  • 登録時の情報: ユーザー名、メールアドレス、ハッシュ化されたパスワード
  • 認証情報: パスキー (WebAuthn 公開鍵)、リカバリコードのハッシュ値
  • 家計簿データ: 仕訳、勘定科目、出納帳の入力内容、月次確定状態
  • 証憑データ: 利用者がアップロードした証憑画像とそのメタデータ (有償オプション契約時のみ永続保管)
  • 連携情報: 外部 AI プロバイダの API キー (Fernet 暗号化保管)、 OAuth トークン、API キー
  • 顧問連携情報: 顧問との関連付け (AuditGrant)、権限レベル
  • アクセス・操作ログ: IP アドレス、ユーザーエージェント、操作種別、 タイムスタンプ
  • 決済関連情報: 外部決済プロバイダの顧客 ID、サブスクリプション状態。 クレジットカード番号等の支払手段の詳細は当方サーバーに保存せず、 決済プロバイダの管理下に保管されます。

2. 利用目的

  • 本サービスの提供・運営、利用者の認証
  • 家計簿データの保管・集計・帳票出力
  • 顧問連携機能の提供 (利用者が許諾した範囲での顧問への閲覧提供)
  • AI 証憑解析機能の提供 (利用者が選択した AI プロバイダへの送信)
  • 有償オプションの料金請求、契約状況の管理
  • 不正利用・規約違反の検知と防止
  • サポート対応、お問い合わせへの回答
  • サービス改善のための統計分析 (個人を特定しない形に加工した上での)

3. 第三者への提供

以下の場合を除き、利用者の同意なく個人情報を第三者に提供しません:

  • 法令に基づく場合 (税務調査・捜査機関の照会等)
  • 利用者の生命・身体・財産の保護のために必要な場合
  • AI 証憑解析機能で利用者が選択した外部 AI プロバイダへの送信 (利用者の指示に基づく)
  • 決済の処理のための外部決済プロバイダへの提供 (利用者の同意に基づく)
  • 顧問連携機能で利用者が許諾した顧問への閲覧提供

4. API キー等の機密情報の取扱い

利用者が登録する外部 AI プロバイダの API キーは、Fernet 方式 (AES-128-CBC + HMAC-SHA256) で暗号化したうえでデータベースに保管 します。当方の運用において以下の取扱いを行います:

  • 復号化が必要な場面 (利用者の指示による外部 API 呼び出し時) を 除いて、API キーの平文は当方のシステム上で取り扱いません。
  • サポート対応・ログ出力・バックアップ・スクリーンショット等で 平文の API キーが出現しないことを運用上の基本ルールとします。
  • 暗号化に使用する鍵は本サービスのサーバー設定として管理し、 データベースとは別の管理対象として保管します。
  • 万一、当方の管理下で API キーが漏えいしたことが判明した場合、 利用者に遅滞なく通知し、影響範囲・原因・対応内容を可能な範囲で 開示します。利用者は速やかに API キーを発行元プロバイダで失効・ 再発行 (ローテーション) する責任を負います (利用規約第 10 条)。

5. 保存期間

  • 家計簿データ・仕訳・証憑データ: 利用者が削除しない限り保管 (電子帳簿保存法の保管期間を考慮)
  • アクセスログ・操作ログ: 取得後 1 年間を目安に保管、その後削除
  • 退会後の取扱い: 退会申請後、合理的な期間内に個人情報を削除 または匿名化します。法令上保管義務がある情報 (帳簿関連等) は 法定期間に限り保管します。

6. セキュリティ対策

当方は以下のセキュリティ対策を講じます:

  • パスワードのハッシュ化保管 (平文では保管しない)
  • パスキー (WebAuthn) によるフィッシング耐性のある認証手段の提供
  • 外部 API キーの Fernet 暗号化保管
  • HTTPS による通信暗号化
  • CSRF・XSS・SQL インジェクション・IDOR 等の Web 脆弱性対策
  • レート制限による不正アクセスの抑止
  • 依存ライブラリのセキュリティ更新

ただし、インターネット上で完全な安全性を保証することはできません。 利用者ご自身でも強固なパスワード設定・パスキー利用・端末の管理等 に努めてください。
